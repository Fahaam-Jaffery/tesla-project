# Tesla — Electric, reimagined

A cinematic, responsive Tesla-inspired product experience built with React and Vite. Scroll-led storytelling, model selection, responsive navigation, and lightweight motion.

## Use the hosted experience

Open the Vercel deployment. No local setup is required to browse the website or review a preview deployment.

## Optional local development

If you want to run the project on your own computer, install Node.js 20 or newer, then run:

```bash
npm install
npm run dev
```

## Production build

GitHub Actions installs the project dependencies on its hosted runner and runs the production build automatically for pull requests and pushes to `main`. You do not need to install project dependencies locally to review a preview deployment.
